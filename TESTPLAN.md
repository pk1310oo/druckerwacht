# Test am echten Drucker (vor dem Veröffentlichen)

Dauer: etwa 20 Minuten. Material: ein kleiner Testwürfel (z. B. 20 mm), PLA.
Bei jedem Punkt einfach abhaken oder notieren, was passiert ist.

## 1. Verbindung
- [ ] App starten → oben grüner Punkt „Verbunden“
- [ ] Einstellungen → „Im Netz suchen“ findet den Drucker
- [ ] Drucker kurz ausschalten → App zeigt „Verbindung verloren“, nach dem Einschalten verbindet sie sich von selbst

## 2. Slicen und Senden
- [ ] Slicer → Würfel laden → Slicen → Vorschau erscheint
- [ ] **Drucken** → Haken „Die Druckplatte ist frei und sauber.“ → **Nur hochladen**: Datei erscheint am Druckerdisplay in der Dateiliste
- [ ] Nochmal **Drucken** → **Hochladen & drucken**: Die App meldet „Der Drucker hat den Druck gestartet“ und wechselt zum Dashboard
- [ ] Dashboard zeigt „Vorbereitung“ (Heizen/Leveling), danach „Druckt“

## 3. Steuern (während der Würfel druckt)
- [ ] **Pause** → Drucker fährt den Kopf weg, App zeigt „Pausiert“
- [ ] **Fortsetzen** → Drucker druckt weiter, App zeigt „Druckt“
- [ ] **Abbrechen** → Rückfrage → „Ja, abbrechen“ → Drucker stoppt, App zeigt das Ende

## 4. Verlauf und Infos
- [ ] Verlauf → „Vom Drucker“ zeigt frühere Drucke (mit Vorschaubild, falls vorhanden)
- [ ] Verlauf → „Diese App“ zeigt den abgebrochenen Testdruck
- [ ] Einstellungen → „Über Druckerwacht“ zeigt Version 0.5.0

## Wenn etwas nicht klappt
In den Einstellungen „Rohdaten mitschneiden“ einschalten, den Schritt wiederholen und die Datei aus dem angezeigten Ordner schicken.
